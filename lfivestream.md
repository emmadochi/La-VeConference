# Integrating vMix Livestream into La-Vie (RTMP Ingest)

This document outlines the architecture and implementation steps required to allow a vMix broadcast to be streamed directly into the La-Vie platform, functioning similarly to a Facebook Live or Instagram RTMP ingest.

## How it Works (The Architecture)

Since La-Vie uses **LiveKit** for real-time video/audio, we can achieve this using **LiveKit Ingress**.

1. **The Ingest Server:** We set up the **LiveKit Ingress** service alongside the existing LiveKit server. This service acts as an RTMP server.
2. **Generating the Key:** From the Python backend (`main.py`), when an admin wants to start a "vMix broadcast," the backend calls the LiveKit API to create an "Ingress." 
3. **The Handshake:** The API returns an **RTMP URL** and a **Stream Key**. These are displayed to the admin in the La-Vie interface.
4. **Streaming:** The admin copies those details into vMix (using the Custom RTMP destination setting) and clicks stream.
5. **Playback:** The Ingress service receives the RTMP feed from vMix, converts it into low-latency WebRTC, and automatically publishes it into the LiveKit Room as a participant (e.g., named "Main Stage"). Everyone in the La-Vie app instantly sees the vMix stream with sub-second latency.

## Implementation Steps

### 1. Install & Run LiveKit Ingress
The `livekit-server.exe` currently handles the core WebRTC rooms. We need to run the companion service: **LiveKit Ingress**.
* LiveKit strongly recommends running Ingress via **Docker** because it requires specific media encoding libraries (like GStreamer/FFmpeg) that are pre-packaged in their container.
* Once running, the Ingress service connects to the Redis instance and the main LiveKit server.

### 2. Update the Python Backend (`main.py`)
We need to add a new API endpoint to generate the RTMP connection details. 

* Use the `livekit-api` Python SDK.
* Create a route (e.g., `POST /create-rtmp-stream`).
* Call the `CreateIngress` method. We will specify that we want an RTMP ingress and map it to a specific room name and participant identity (e.g., `participant_identity: "vmix_main_feed"`).
* Return the `url` and `stream_key` generated by LiveKit back to the frontend.

### 3. Update the Frontend / App UI
The La-Vie client (Flutter/Web) needs updates to handle this new flow:
* **Host UI:** Create a "Generate RTMP Key" button in the admin/host dashboard. When clicked, it displays the RTMP URL and Stream Key for the user to copy into vMix.
* **Viewer UI:** Ensure the participant layout handles the incoming vMix feed correctly. Since the vMix stream joins as a standard participant, you may want to add UI logic to "pin" or "spotlight" this specific participant (e.g., checking if the participant's identity is `vmix_main_feed`) so it acts as the main stage presentation rather than just a small tile in a grid.
